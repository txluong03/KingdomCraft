# Settings — KingdomCraft

## Mục đích
Thiết kế màn hình cài đặt trò chơi (đồ họa, âm thanh, điều khiển,
gameplay) — áp dụng cho cả bản đơn (Client) và các tùy chọn kết nối
multiplayer.

## Nội dung cần điền
- Nhóm cài đặt: Đồ họa (độ phân giải, render distance chunk), Âm thanh
  (liên hệ [[Audio]]), Điều khiển ([[Controller]]), Gameplay (độ khó, tự
  động lưu)
- Tùy chọn HUD (bật/tắt thành phần, độ trong suốt) — liên hệ [[HUD]]
- Cài đặt tài khoản/kết nối server (liên hệ [[Authentication]],
  [[MultiplayerAPI]])
- Reset về mặc định, lưu/khôi phục theo profile người chơi
- Cài đặt trợ năng riêng hay gộp chung vào Settings (liên hệ
  [[Accessibility]])
- Bản địa hóa ngôn ngữ hiển thị

## Câu hỏi mở
- Cài đặt lưu ở đâu (file cấu hình local, hay đồng bộ theo tài khoản qua
  [[SaveAPI]])?
- Có cần preset độ khó/gameplay riêng cho từng giai đoạn Progression hay
  áp dụng chung toàn bộ ván chơi?

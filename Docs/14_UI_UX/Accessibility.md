# Accessibility — KingdomCraft

## Mục đích
Định hướng các tính năng trợ năng (accessibility) giúp người chơi khuyết
tật thị giác/thính giác/vận động tiếp cận được game — áp dụng xuyên suốt
các màn hình UI khác (HUD, Inventory, Crafting, Kingdom, Settings).

## Nội dung cần điền
- Chế độ hỗ trợ màu (colorblind mode) cho các cảnh báo/chỉ số quan trọng
  (Health, Happiness thấp, tài nguyên thiếu)
- Tùy chọn phóng to chữ/UI scale, độ tương phản cao
- Phụ đề/hiển thị văn bản thay thế cho tín hiệu âm thanh (cảnh báo, sự
  kiện)
- Hỗ trợ điều khiển thay thế (remapping đầy đủ, hỗ trợ hold-thay-vì-mash
  cho thao tác lặp)
- Tùy chỉnh tốc độ/độ phức tạp thông tin hiển thị (giảm rối mắt cho người
  chơi nhạy cảm)
- Tuân thủ tiêu chuẩn trợ năng phổ biến từ nền tảng phát hành mục tiêu

## Câu hỏi mở
- Mức đầu tư trợ năng nào khả thi với quy mô đội hiện tại (rất nhỏ) — ưu
  tiên tính năng nào trước (colorblind mode, remap phím) so với tính năng
  nào có thể làm sau?
- Có yêu cầu tuân thủ bắt buộc nào từ nền tảng phát hành mục tiêu (VD:
  Xbox/PlayStation accessibility guidelines) ảnh hưởng phạm vi ngay từ
  đầu?

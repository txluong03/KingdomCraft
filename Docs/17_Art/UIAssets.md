# UI Assets — KingdomCraft

## Mục đích
Định hướng hình ảnh cho giao diện (HUD, inventory, bảng quản lý vương
quốc). Hiện **chưa có UI/UX hay asset giao diện nào** được triển khai, đây
là khung chuẩn bị.

## Nội dung cần điền
- Phong cách UI tổng thể (tối giản, kiểu trung cổ/kingdom, kiểu pixel...)
- Icon cho từng `NpcRole`, tài nguyên, công trình
- Giao diện quản lý vương quốc (bảng điều khiển `AutomationLevel`, danh sách NPC)
- Font chữ và khả năng đọc ở độ phân giải thấp
- Responsive cho các độ phân giải màn hình khác nhau
- Icon/chỉ báo trạng thái tiến trình (thanh `AutomationLevel`, huy hiệu giai đoạn)

## Câu hỏi mở
- UI có theme thay đổi theo giai đoạn tiến trình (giao diện "quê mùa" ban đầu, "hoàng gia" khi lên Vua) không?
- UI được xây bằng công nghệ/framework nào (phụ thuộc engine hiện dùng)?
